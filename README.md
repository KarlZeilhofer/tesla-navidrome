# Tesla Navidrome

Tesla-optimized web UI for Navidrome/OpenSubsonic.

Initial goals:

- reuse an existing Navidrome login from the same origin
- provide a large-touch UI for the Tesla browser
- search songs
- play via HTML5 audio
- manage a local in-page queue
- star/unstar songs

The first deployment target is `/tesla/` on the same origin as Navidrome.
